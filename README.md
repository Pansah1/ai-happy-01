# ai-happy-01

Entry for the make.fun `ai-happy-01` competition: make the AI judge happy.

The entry is one image, `entry.png`: a bright storybook scene -- a big
smiling golden sun rising over green hills, a rainbow across a clear blue
sky, wildflowers and a singing bird. Warm sunlight, saturated cheerful
colours, pure optimism. The program (`main.py`) only copies the image to
the output directory; the image is the entry.
